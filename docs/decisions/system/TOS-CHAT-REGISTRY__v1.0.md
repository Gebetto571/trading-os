# Trading OS Sohbet Kimlik Defteri

| chat_key | Rol | Karar kapsamı | Durum |
|---|---|---|---|
| `docs-manager` | Drive, belge, klasör, adlandırma, tasnif ve senkronizasyon | Belge yönetimi ve kayıt sistemi | active |
| `cloud-planner` | Analiz, planlama ve Codex görev kartı hazırlama | Plan ve tavsiye; kod değişikliği yapmaz | active |
| `codex-dev` | Kodlama, test, Git ve GitHub uygulaması | Yetkili görev kapsamındaki kod değişiklikleri | active |
| `all-chats` | Bütün Trading OS sohbetleri | Ortak bildirim hedefi | virtual |

Yeni sohbet için anahtar ekleme biçimi:

```text
<yuzey>-<islev>-<istege-bagli-konu>
```

Örnek: `codex-dev-risk`, `cloud-planner-polymarket`.
